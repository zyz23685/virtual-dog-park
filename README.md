# Virtual Dog Park

A beginner-friendly virtual dog park for the AIE1101 Week 5 Lab 2.

## Features
- Dog Encyclopedia: Beagle, Golden Retriever, and Poodle
- Local SVG illustrations with alt text
- Adopt one virtual dog with a name of up to 20 characters
- Feed and Play: +10 happiness, maximum 100
- Next Day: +1 day and -5 happiness, minimum 0
- Growth: Day 1 Puppy, Days 2–3 Young Dog, Day 4 onward Adult Dog
- localStorage restores one dog after refresh
- Start Over confirms before deleting saved progress

## Preview
Open `index.html` with VS Code Live Server or another local server.

## Manual checklist
Test adoption, invalid names, Feed, Play, Next Day, refresh restoration, Start Over cancel/confirm, and narrow-screen layout.

Progress is stored locally in the same browser and device, not in a GitHub account. The SVG illustrations were created for this project; they are not real dog photographs.
